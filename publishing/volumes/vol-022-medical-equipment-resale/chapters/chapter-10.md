## 1. Build one serial ledger and divide the six-person pod by decision authority  `🏷️ OPERATING_FRAMEWORK`

Organize Candidate #14 around three explicitly mapped operating plays: diagnostic fleet refresh for imaging and diagnostic instruments, surgical equipment redeployment for documented systems and accessories, and veterinary/aesthetic specialty resale for devices with verified intended use and service support. These are operating lanes, not separate revenue forecasts. Give the first full-time operator purchasing, pricing, cash allocation, and buyer commitments; give the second inventory control, evidence quality, workflow maintenance, and dispatch coordination. Assign four contractors to biomedical evaluation, specialist repair, decontamination and preparation, and freight and installation coordination, subject to actual qualifications. Contractor availability must appear as booked capacity rather than assumed continuous coverage. Across all three plays, the shared automation backbone performs intake normalization, document indexing, buyer matching, and status propagation. It never determines electrical safety or invents missing maintenance. Reserve two daily exception windows so purchasing questions do not interrupt every bench task. Each unresolved item receives an owner, evidence request, and expiration time. When specialist capacity is full, purchasing slows before unfinished inventory consumes cash. This division preserves the canonical 2 FT + 4 C constraint while making the actual bottleneck visible: qualified release hours, not the number of descriptions a model can draft.

Create a Python service around a serial-level asset ledger, initially using sqlite3 transactions and an append-only event table on a single managed host. Assign an internal asset UUID because manufacturer serial formats can collide across brands. Store manufacturer, model, serial, configuration, accessory manifest, acquisition cost, location, custody, commercial reservation, and technical status separately. A technical state machine moves from received to quarantined, evaluated, repaired when necessary, tested, and released; commercial states track available, reserved, sold, and returned. A released asset can still be unavailable because another buyer holds its reservation. Use UNIQUE constraints for external event identifiers and atomic conditional updates for reservation changes. Link service documents through immutable object identifiers, hashlib SHA-256 digests, document dates, and controlled storage locations. Preserve revisions instead of replacing old evidence. A nightly reconciliation compares physical location scans, reservations, marketplace listings, and the accounting inventory balance. Begin with a CSV exception report that a person can understand before adding dashboards. Test duplicate serials, partial kits, missing probes, and returns with changed accessories. An elegant record that cannot distinguish the machine from its separately priced transducer will create expensive fulfillment errors long before it creates useful automation. Photograph labels during intake and reconcile them against the ledger before any listing leaves draft.

Treat supplier forms, marketplace notifications, and freight callbacks as untrusted events entering the same durable inbox. Verify provider signatures using hmac.compare_digest where the provider supports shared-secret signing, enforce timestamp tolerance, and record the event before acknowledging receipt. Fetch authoritative order details through authenticated APIs when callbacks contain only references. A worker validates the schema, checks asset identity, performs the permitted transition, and writes an outbound task within the same database transaction. This transactional outbox prevents a successful reservation from losing its listing-removal request during a crash. Workers retry transient failures with bounded exponential delays and jitter; permanent validation failures move to an exception queue. Never retry a payment, shipment purchase, or buyer message blindly after a timeout. First query the provider using the original idempotency key or order reference. An inventory heartbeat detects stale integrations and suspends affected channel availability until reconciliation. Keep a printable released-stock list and a controlled manual reservation log for outages, then merge those entries before restarting publication. Log actor, previous state, new state, evidence identifiers, and correlation ID without copying patient information into application logs. Recovery must restore the physical-commercial truth, not merely restart a process that was already publishing the wrong stock.

1. Receive and isolate
   - Create the asset UUID and quarantine the physical device.
   - Photograph identifiers, record custody and accessories, and route media containing patient information into restricted handling before external processing.
2. Normalize and link
   - Build the serial ledger and index the authorized service packet.
   - Hash each document, preserve its revision, and attach extracted claims to page-level evidence without converting absent records into completed service.
3. Review and release
   - Obtain separate technical release and commercial publication decisions.

   - Compare physical inventory, open reservations, published stock, and dispatched orders.

## 2. Index service histories without delegating safety, patient-data handling, or device claims  `🏷️ OPERATING_FRAMEWORK`

Service-history indexing begins with a restricted document landing area, not a public chat interface. Classify incoming files by asset, document type, date, source, and potential patient content. An operator separates service records from clinical exports, DICOM studies, screenshots, and embedded storage images before any external model submission. Where the relationship creates business associate duties, execute the required agreement and configure safeguards before handling electronic protected health information for the covered entity. HIPAA applicability depends on the parties and activity; purchasing used equipment alone does not resolve that analysis. Apply 45 CFR 164.310(d) media controls where applicable and select sanitization procedures appropriate to the actual storage technology. A factory reset is evidence of a reset, not proof that every storage component was sanitized. Inventory removable disks, service partitions, printer storage, and cached network credentials. Record the method, verification result, technician, asset identifier, and disposition of failed media. If sanitization would damage validated configuration or licensed software, stop and obtain an authorized service path. Keep clinical material out of the resale knowledge base; a service index should answer what was tested and repaired, not reveal who was examined. Restrict access by role and retain only the records necessary for the documented transaction and applicable obligations.

For cleared records, combine OCR with a constrained extraction request that returns document date, observed serial, procedure, measured results, parts replaced, software revision, and supporting page references. Python's json module can parse the response, but application validators must enforce required fields, length limits, allowed units, and exact asset matches. Treat every document instruction as source text, never as permission to change the extraction policy or contact another service. Use SQLite full-text search when available, with a keyword fallback, before buying a separate vector database. Retrieve the smallest relevant packet and require each generated claim to cite an existing document and page. Missing preventive maintenance becomes a request for evidence, not a fabricated interval or a reassuring adjective. Confidence scores prioritize review; they do not establish accuracy. A model can draft a service chronology, identify contradictory dates, and flag a serial mismatch, while a qualified reviewer resolves those conflicts. Build a test corpus containing rotated scans, handwritten corrections, mixed-device invoices, and superseded reports. Measure field-level precision, unsupported claims, serial attribution errors, and review minutes. A shorter summary that omits an uncertain assertion is operationally superior to a polished narrative that attaches another machine's calibration certificate.

Separate ordinary servicing from changes that could make the business a remanufacturer. FDA's servicing and remanufacturing guidance focuses on whether activities significantly change performance, safety specifications, or intended use; a cosmetic label such as refurbished does not settle the classification. Route changed energy output, altered software functions, substituted critical components, and modified intended-use claims to device-specific assessment before work or marketing proceeds. Where manufacturer requirements attach, evaluate registration and listing under 21 U.S.C. 360 and 21 CFR Part 807, applicable premarket obligations, and the Quality Management System Regulation under 21 CFR Part 820. Do not automatically assign those obligations to every domestic reseller, and do not assume a reseller exemption covers importing or manufacturing activities. Identify state licensing and radiation-control requirements for the equipment and destination. Surgical systems need accessory and sterilization compatibility evidence; diagnostic systems need configuration and performance evidence; veterinary/aesthetic transactions need especially careful intended-use and buyer-use checks. Veterinary-only status does not make a device exempt from every applicable control. The publication workflow should block unsupported safety, certification, clearance, and outcome claims. Release requires a signed technical packet and a separately reviewed commercial description, both linked to the exact configuration offered rather than merely the model family.

> **OPERATOR GATE — Four checks before a device becomes publicly available**
> 
> Automation can assemble the packet, but named reviewers must close these four checks for the actual serial and offered configuration.
> - Match the photographed manufacturer, model, serial, software revision, and accessory manifest to the ledger and every cited test report.
> - Require signed device-specific biomed results and documented decontamination using compatible procedures before technical release.
> - Verify patient-data disposition across all identified media and resolve storage failures through a documented authorized service path.
> - Resolve servicing classification, applicable licensing, buyer-use restrictions, and unsupported claims before approving the listing.

## 3. Turn released inventory into programmatic, referral, and outbound distribution loops  `🏷️ OPERATING_FRAMEWORK`

Build programmatic distribution from released inventory rather than generating thousands of speculative product pages. Each asset page should expose verified configuration, included accessories, documented condition, supported service region, shipping constraints, and an appropriately redacted evidence summary. Publish availability from the reservation ledger and remove purchase actions immediately when stock becomes unavailable. Separate durable model-family guides from serial-specific offers so sold stock does not leave a trail of misleading availability. Google Search Console can identify useful queries, but search impressions are not qualified demand. Measure inquiries that identify a buyer, use case, destination, budget range, and purchasing timeframe. Diagnostic fleet refresh pages answer probe compatibility and installation questions; surgical pages explain complete-system and accessory boundaries; veterinary/aesthetic pages distinguish documented intended use from buyer assumptions. Use actual photographs with licensed rights and redact hospital identifiers. A Python publishing job renders approved fields into templates, validates outbound links, and queues previews for commercial review. Only previously approved factual fields may update automatically afterward. Material configuration or performance changes require fresh review. Maintain a page revision identifier on every inquiry so the sales operator can reconstruct precisely what the buyer saw, including the offered accessories and stated delivery conditions at the time of contact.

Create an evidence-sharing loop that helps a buyer complete internal evaluation. After qualification, issue an expiring link to a redacted technical packet containing the actual serial, configuration, test summary, accessory checklist, and delivery requirements. Let the buyer invite their biomedical engineer or procurement colleague without exposing another customer's records or unrestricted service files. Track packet requests and subsequent questions at the account level rather than treating every recipient as a new lead. Successful installations can produce permissioned case studies about operational facts, such as configuration delivered and installation coordination, without patient outcomes or unsupported clinical claims. Service contractors can refer facilities planning replacements, while satisfied buyers can request alerts for matching inventory. Keep referral compensation transparent and review arrangements that intersect federally reimbursed business before implementation, including potential 42 U.S.C. 1320a-7b(b) exposure. Avoid paying clinicians simply for steering reimbursable business. The flywheel is specific: better evidence shortens technical diligence, completed transactions produce permissioned references, references attract better sellers and buyers, and better acquisitions improve the next evidence packet. Measure each link separately. A widely forwarded packet that produces no suitable inquiries has generated distribution activity, not a proven acquisition advantage or permission to increase inventory commitments.

Outbound begins with a small, documented account universe, not scraped personal contact lists. Segment facilities by supported equipment family, geography, service coverage, and plausible replacement timing. Use public organizational information and authorized CRM records to draft relevant messages without asserting that a facility owns a particular machine unless that fact is verified. For commercial email, implement accurate sender information, nondeceptive subjects, a valid postal address, and functioning opt-out handling under 15 U.S.C. 7704. Synchronize suppression records before every send and honor applicable opt-out deadlines. Do not silently expand the workflow into automated calling or texting; those channels require separate analysis of applicable rules. A human approves the initial segment, offer, and message template. Automation may then match released assets, prepare individualized drafts, schedule permitted sends, and route replies. Buyer qualification extracts requested configuration, intended use, location, installation needs, and timeline, but humans resolve suitability and unusual payment or export arrangements. Stop sequences immediately on a reply, opt-out, reservation conflict, or stale availability signal. Attribute deals using account and asset identifiers, deduplicate referrals against outbound records, and report acquisition cost per completed sale. More email cannot compensate for an unavailable device or a buyer whose installation requirements the pod cannot support.

> **INSIDER PRO-TIPS — Make the evidence packet do the selling**
> 
> Experienced equipment traders reduce buyer uncertainty before increasing traffic. These tactics strengthen all three operating plays.
> - Photograph the serial plate, software version screen, connectors, and included accessories during one controlled intake session; reusing verified images prevents repeated warehouse interruptions.
> - Index service histories by serial plus component identifier, not only model name; probes, handpieces, and modules often carry the evidence that determines whether a system is saleable.
> - Record doorway dimensions, lift requirements, receiving hours, and installation responsibility before quoting freight for large diagnostic or surgical systems.
> - Keep sold model-family pages useful with factual buying guides and opt-in availability alerts, while clearly removing the sold serial from active purchase and reservation paths.

## 4. Prove automation economics, rehearse recovery, and scale only the supported workload  `🏷️ ILLUSTRATIVE_MODEL`

Define the 70% target before instrumenting the workflow. Use repetitive task episodes such as intake normalization, service-document indexing, qualification-field extraction, shipment-status routing, and approved availability updates. Freeze the task taxonomy and baseline handling times for the measurement period; do not split easy tasks into smaller units after seeing results. An illustrative monthly cohort contains 1,000 episodes, of which 740 complete correctly without human intervention and 260 require exception work. That yields 74% touchless completion, but it does not automatically yield 74% labor savings. If baseline repetitive handling averages six minutes per episode, the original load is 6,000 minutes. At five minutes per exception, plus 200 minutes of sampled review and 200 minutes of maintenance, the remaining repetitive-work burden is 1,700 minutes: a 71.7% reduction. Validate those times through observation rather than adopting them as operating facts. Technical testing, physical preparation, commercial release, and consequential buyer decisions remain outside the repetitive-task denominator and still require staff capacity. Report their hours beside the automation percentage so leadership cannot mistake narrower administrative savings for whole-business automation. If rework or monitoring increases, include it immediately. A single erroneous configuration propagated to six channels is one source defect with six cleanup obligations, not six successful automated episodes.

Price automated runs using explicit assumptions and reconcile them to the scorecard without claiming that software creates additional margin automatically. For an illustrative indexed-document run, assume 8,000 input tokens at $2 per million and 1,000 output tokens at $8 per million, producing $0.024 of model usage. Add $0.010 for OCR and $0.006 for allocated queue, storage, and compute: $0.040 per run. These are planning assumptions, not vendor quotations. At 1,000 runs, direct usage is $40. If a costed review sample covers 10% of runs for two minutes each at $45 per hour, it adds $150, or $0.190 per run including that review. This narrow sample matches the 200 review minutes above but excludes exception labor, maintenance, physical work, and fixed business software. The canonical Conservative case remains $250,000 revenue less $225,000 total costs, yielding $25,000 owner profit. Base remains $1,025,000 less $861,000, yielding $164,000; Scaled remains $1,800,000 less $1,404,000, yielding $396,000. These are gross equipment resale proceeds, not commission revenue or customer equipment value handled for others. Acquisition and refurbishment stay inside the cost envelope. Allocate payroll, contractor utilization, freight, returns, insurance, storage, and automation within those totals rather than adding imagined savings to the stated owner profits.

Run a monthly recovery exercise on a copy of operational data with patient material excluded. Replay duplicate callbacks, interrupt an outbound listing update, expire an API credential, submit an unreadable service scan, and reserve the same asset concurrently from two channels. Expected behavior is controlled quarantine, one valid reservation, preserved evidence, and a visible owner for each unresolved exception. Restore a backup into an isolated environment and compare asset counts, reservation balances, document hashes, and open shipment references before declaring recovery successful. During model outages, revert to deterministic field extraction and manual indexing; during marketplace outages, stop affected publication and maintain the source ledger. During carrier outages, prepare documents manually but confirm whether a shipment already exists before purchasing another label. Review aging stock weekly by model support, parts availability, carrying cost, and realistic exit value. Automation should accelerate markdown or parts-recovery decisions when evidence supports them, not conceal unsellable inventory behind fresh traffic. The Scaled case explicitly expands to 3 FT + 5 C; assign added capacity to the measured bottleneck rather than claiming the six-person pod produces that case unchanged. Buy additional inventory only when released-stock throughput, specialist availability, cash conversion, and exception burden support it. The distribution flywheel must remain subordinate to device safety and cash discipline.
